# فونت IRANSans

IRANSans یک فونت **دارای مجوز تجاری** است و در این پروژه گنجانده نشده — باید نسخه‌ی مجاز خودت رو اینجا قرار بدی.

فایل‌های موردنیاز (دقیقاً با همین اسم‌ها، فرمت woff2 ارجحه، woff هم به‌عنوان پشتیبان):

```
fonts/
  IRANSansWeb_Regular.woff2
  IRANSansWeb_Regular.woff
  IRANSansWeb_Medium.woff2
  IRANSansWeb_Medium.woff
  IRANSansWeb_Bold.woff2
  IRANSansWeb_Bold.woff
```

بعد از قرار دادن این فایل‌ها و پوش کردن به ریپو، سایت خودکار از IRANSans استفاده می‌کنه — چیزی توی کد تغییر نمی‌خواد.

اگه هنوز فایل‌ها رو اضافه نکردی، سایت به‌صورت خودکار (بدون خطا) با فونت **Vazirmatn** نمایش داده می‌شه، چون در `css/style.css` به‌عنوان جایگزین تعریف شده.
